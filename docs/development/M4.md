# M4 HTTP 與 Handler 驗證證據

`waveio-http` 僅依賴 WaveIO lower layers 與 JDK，沒有 Netty 型別。Request／response metadata、headers、URI 與 body 都是 transport-independent contracts。

Memory fixture 使用 production `ExecutionRuntime` 和 `Task` 執行 handler chain。Router 使用 exact path segments，支援 immutable path parameters、404、405/`Allow` 與 GET→HEAD matching；HEAD 保留 status/headers 並抑制 body subscription。

驗證結果：`mvnw verify` 通過（含 10 個 HTTP module tests）；Netty-isolation scan 與
`git diff --check` 通過。GitHub Actions run `34176585523` 於 Ubuntu 與 Windows 均以
Microsoft JDK 25 成功執行 wrapper `verify`。
