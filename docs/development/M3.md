# M3 Task、Blocking 與 Flow

`Task<T>` 是單一結果的延遲描述。組合或建立 Task 不會啟動工作；每一次 terminal start 都會建立獨立執行狀態。Task continuation 必須回到所屬 execution，外部 `CompletionStage` 的 callback 不保證帶有 WaveIO context。

M3 的 blocking bridge 採 virtual thread，具明確 concurrent slot 與等待 queue 上限；取消只中斷 runtime 擁有且合作的工作。Flow bridge 只服務 HTTP body 所需的 demand、cancel 與 bounded byte-buffer collection，不提供通用 reactive operator framework。

Task timeout 不會延長 parent execution deadline；parent deadline 或 cancellation 會完成 exported Task stage，並丟棄晚到 callback。
