# M7 首版發布驗證證據

M7-01 固定 `0.1.0` 的 public/internal boundary，並將 JPMS exports inventory 寫入
[`docs/API_COMPATIBILITY.md`](../API_COMPATIBILITY.md)。Netty transport 維持 qualified export；公開
consumer 入口為 foundation、execution、task、http、server 與 testkit modules。

0.x patch 不得破壞 public API；minor 的 breaking change 必須記錄 migration impact。Java 25 是唯一
CI 驗證及支援的 JDK，無 preview API 或 compiler flag。

驗證結果：module descriptors 與 `mvnw -B -ntp verify` 通過；API inventory 與全部 exports 對照完成。
