# M2 Execution Runtime

M2 的 runtime 以一個 managed execution 表達一次邏輯操作。它只會從 `ACTIVE` 過渡一次到 `SUCCEEDED`、`FAILED`、`CANCELLED` 或 `TIMED_OUT` 其中之一；第一個 terminal signal 獲勝，之後的 callback 不得重新啟動或更改結果。

容量不足使用 `ExecutionRejectedException` 明確表示。deadline 以 `ExecutionDeadlineExceededException` 表示，外部取消以 `ExecutionCancelledException` 表示。cleanup 採 LIFO 且其失敗會交給 `CleanupFailureObserver`；實作會保留既有 terminal state。

runtime 顯式指定 queue capacity、parallelism 與 deadline，沒有隱性無界預設。所有跨執行緒 callback 要透過 `ExecutionRef` 回到 per-execution serial dispatcher；`Execution.current()` 僅在 managed segment 可用。deadline、cancel、成功與失敗競逐同一個 terminal transition；已終止 execution 丟棄晚到 callback。cleanup 以 LIFO 執行，failure 經 observer 回報而不覆寫既有 terminal state。
