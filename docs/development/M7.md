# M7 首版發布驗證證據

M7-01 固定 `0.1.0` 的 public/internal boundary，並將 JPMS exports inventory 寫入
[`docs/API_COMPATIBILITY.md`](../API_COMPATIBILITY.md)。Netty transport 維持 qualified export；公開
consumer 入口為 foundation、execution、task、http、server 與 testkit modules。

0.x patch 不得破壞 public API；minor 的 breaking change 必須記錄 migration impact。Java 25 是唯一
CI 驗證及支援的 JDK，無 preview API 或 compiler flag。

驗證結果：module descriptors 與 `mvnw -B -ntp verify` 通過；API inventory 與全部 exports 對照完成。

M7-02 在 `verify` 附加每個 module 的 binary、sources 與 Javadoc JAR，產生 module dependency
report。`scripts/assemble-distribution.ps1` 將這些 artifacts、`LICENSE`、`NOTICE` 與排序的 SHA-256
manifest 組裝至 `target/distribution/waveio-<version>`；Maven archive timestamp 固定以保證可重現。

驗證結果：`mvnw -B -ntp -DskipTests verify` 及 `scripts/assemble-distribution.ps1` 通過；distribution
包含單一 `waveio` artifact 的 binary/sources/Javadoc JAR、dependency report 與 `SHA256SUMS`。

M7-03 的 `consumer-verification` 是不在 reactor 的獨立 JPMS module。`scripts/verify-consumer.ps1`
只把 distribution 的 artifact JAR 及 Netty runtime dependencies 放入 module path，使用 public
`WaveServer` facade 編譯、bind 並關閉最小服務；不使用任何 reactor `target/classes`。

驗證結果：`scripts/verify-consumer.ps1` 通過。

M7-04 將 `scripts/verify-release-gates.ps1` 納入 GitHub Actions 的 Ubuntu/Windows Java 25 matrix。
gate 精確比較每個 JPMS descriptor 的 exports baseline，拒絕 preview flag，並確認 runtime Java version
為 25；既有 wrapper `verify` 繼續是每個平台的前置檢查。

驗證結果：`scripts/verify-release-gates.ps1` 與 `git diff --check` 通過。

M7-05 提供可重跑的 reliability suite，覆蓋 real-socket restart/slow-peer/chunked/keep-alive、paranoid
Netty leak detection、execution cancellation/capacity、blocking saturation 與 bounded Flow collection。

驗證結果：`scripts/run-reliability.ps1 -Iterations 3` 通過，三輪皆無 test failure 或 leak failure。

M7-06 建立 benchmark runner，分開量測 execution/Task micro workload 與 HTTP real-socket workload，並
輸出 JDK、OS、CPU、logical processors、resource config、iteration count 及每類總／平均毫秒至
`target/benchmark-report.md`。

驗證結果：`scripts/run-benchmarks.ps1 -Iterations 1` 通過；此環境的 report 已產生，並保留 runner
供 release 前以較高 iteration count 重跑。

M7-07 建立 `CHANGELOG.md`、0.1.0 preview release notes 與 release dry-run。dry-run 驗證 distribution
中的 `waveio` binary/sources/Javadoc JAR、`LICENSE`、`NOTICE`、dependency report 與
`SHA256SUMS`，只產生本機附件清單，不呼叫 GitHub API。

驗證結果：`scripts/release-dry-run.ps1` 通過，確認 3 個 JAR attachments；外部 GitHub Release command
僅記錄在 release notes，未執行。
