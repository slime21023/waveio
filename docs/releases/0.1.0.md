# WaveIO 0.1.0 preview release notes

此 release 提供 Java 25 HTTP/1.1 application foundation：typed registry、execution、Task/Flow、HTTP
handler/routing、TLS Netty transport、`WaveServer` facade、service lifecycle、response helpers、observation
dispatcher 與 testkit。

支援 Java 25（無 preview）；HTTP/2、WebSocket、JSON、DI 與 Groovy DSL 不在此版本範圍。相容性規則見
[`docs/API_COMPATIBILITY.md`](../API_COMPATIBILITY.md)。

## GitHub Release attachments

- `waveio` 的 binary、sources、Javadoc JAR
- `LICENSE`、`NOTICE`
- 每 module dependency report
- `SHA256SUMS`

建立 release 的最後人工命令（僅在 dry-run 及 CI 都成功後執行）：

```powershell
gh release create v0.1.0 target/distribution/waveio-0.1.0/artifacts/* target/distribution/waveio-0.1.0/LICENSE target/distribution/waveio-0.1.0/NOTICE target/distribution/waveio-0.1.0/SHA256SUMS --title "WaveIO 0.1.0 preview" --notes-file docs/releases/0.1.0.md
```

本 repository 的 dry-run 不會執行此命令。
