# Distribution assembler

This tool is the 0.9-T3 packaging foundation. It intentionally assembles a snapshot jar and
therefore cannot satisfy the 0.8 immutable compatibility prerequisite or produce a signed 1.0
release. `verify-archive.ps1` fails closed when the expected Wave jar or required manifest entries
are missing.

```text
./mvnw -B -ntp -pl wave -am package -DskipTests
./mvnw -B -ntp -f tools/distribution/pom.xml clean package
powershell -File tools/distribution/verify-archive.ps1
```

The release-input commands below are run from `tools/distribution`; their `target/...` paths are
relative to that directory.

An actual release dry-run must additionally provide an owner-controlled public key, detached
signature, and SHA-256 sidecar. `verify-release.ps1` requires all four inputs and fails closed on
missing files, digest mismatch, unavailable OpenSSL, or an invalid signature:

```text
powershell -File ./create-sha256.ps1 \
  -Archive target/wave-0.9.0-rc-distribution.zip
powershell -File ./verify-release.ps1 \
  -Archive target/wave-0.9.0-rc-distribution.zip \
  -Sha256File target/wave-0.9.0-rc-distribution.zip.sha256 \
  -Signature target/wave-0.9.0-rc-distribution.zip.sig \
  -PublicKey release-public.pem
```

On Unix-like CI runners, `bash tools/distribution/create-sha256.sh <archive>` produces the same
GNU-style sidecar. The sidecar contains only the digest and archive filename; signing remains an
owner-controlled step and no key is generated by these helpers.

No key, signature, or release sidecar is checked into this repository.
