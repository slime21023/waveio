# M6 應用開發體驗驗證證據

M6-01 建立 `waveio-server` 與 named JPMS module `io.waveio.server`。`ServerSpec` 是 immutable
server assembly contract，要求 address、handler、registry、`ExecutionConfig`、`ServerLimits` 與
`ServerTimeouts` 全部明確提供。limits 及 request／idle／shutdown timeout 都拒絕零值、負值或 null，
不提供無界或不透明 defaults。

驗證結果：`mvnw -pl waveio-server -am test` 通過；`ServerSpecTest` 覆蓋不合法 limits、timeouts
及遺漏 execution config。

M6-02 提供 `WaveServer.start(ServerSpec)`、`RunningServer.address()` 與
`RunningServer.stop(Duration)`。facade 將 explicit limits／idle timeout 組裝為 transport config，並以
`io.waveio.netty` 的 qualified JPMS export 呼叫 Netty；一般 module 不可讀取該 package。`RunningServer`
擁有 transport/runtime，stop 是 idempotent。

驗證結果：`mvnw -pl waveio-server -am test` 通過；public-facade test 使用真實 socket 收到 `200 OK`
並以 `RunningServer.stop` 關閉 server。
