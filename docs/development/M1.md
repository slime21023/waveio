# M1 Foundation 驗證證據

## 已固定的公開契約

`waveio-foundation` 是唯一的目前 production module，artifact 為 `io.waveio:waveio-foundation:0.1.0-SNAPSHOT`。JPMS module `io.waveio.foundation` 僅 exports `io.waveio.registry`。

Registry 只接受 eager、non-null instance，`Key.of(Class<T>, String)` 以 type 與 name 的 structural equality 識別 binding。沒有 supplier、lazy binding、DI、generic type token 或 `getAll()`。`overlay()` 的 argument 優先，receiver 為 fallback；所有 build 結果都是 immutable snapshot，且不複製 service instance。
